## Features

- ⚡ **Two rendering bases** — Generate PDFs with Takumi or Forme
- 🎯 **Zero config** — Works out of the box with sensible defaults
- 👀 **Live previews** — Render every component and block directly in the documentation
- 🎨 **Fully customizable** — Sensible props and shared themes; you own the code
- 📦 **shadcn/ui compatible** — Uses the same registry format and CLI workflow
- 🧩 **Composable** — Build documents from focused React components and renderer primitives
- 📄 **Components and blocks** — Tables, forms, charts, invoices, reports, and more
