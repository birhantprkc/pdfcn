## Usage

```tsx

```

```tsx

```

| `size`             | `'sm' \| 'md' \| 'lg'`       | `'md'`         |
| `labelFlex`        | `number`                     | `1`            |
| `labelColor`       | `string`                     | -              |
| `valueColor`       | `string`                     | -              |
| `boldValue`        | `boolean`                    | `false`        |
| `noWrap`           | `boolean`                    | `false`        |
| `dividerColor`     | `string`                     | -              |
| `dividerThickness` | `number`                     | -              |
| `dividerMargin`    | `number`                     | -              |
