## Usage

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHeader,
  TableRow,
  Text,
} from "@/components/pdf/table";
```

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableCell>
        <Text>Item</Text>
      </TableCell>
    </TableRow>
  </TableHeader>
</Table>
```

### Variants

```tsx
<Table variant="striped" zebraStripe>
  {/* header, body, rows, and cells */}
</Table>
```

## API Reference

### Table

| Prop          | Type           | Default  |
| ------------- | -------------- | -------- |
| `variant`     | `TableVariant` | `'line'` |
| `zebraStripe` | `boolean`      | `false`  |
| `noWrap`      | `boolean`      | `false`  |
| `children`    | `ReactNode`    | -        |
| `style`       | `Style`        | -        |

### TableRow

| Prop      | Type           | Default |
| --------- | -------------- | ------- |
| `header`  | `boolean`      | `false` |
| `footer`  | `boolean`      | `false` |
| `stripe`  | `boolean`      | `false` |
| `variant` | `TableVariant` | inherited |

### TableCell

| Prop      | Type                             | Default  |
| --------- | -------------------------------- | -------- |
| `header`  | `boolean`                        | `false`  |
| `footer`  | `boolean`                        | `false`  |
| `align`   | `'left' \| 'center' \| 'right'`  | `'left'` |
| `width`   | `string \| number`               | -        |
| `variant` | `TableVariant`                   | inherited |

`TableVariant` is `'line' | 'grid' | 'minimal' | 'striped' | 'compact' | 'bordered' | 'primary-header'`.
