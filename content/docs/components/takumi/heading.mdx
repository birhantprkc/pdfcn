## API Reference

### Heading

| Prop           | Type              | Default     |
| -------------- | ----------------- | ----------- | ------------- | ------ | --- | --- | --- |
| `level`        | `1                | 2           | 3             | 4      | 5   | 6`  | 1   |
| `align`        | `"left"           | "center"    | "right"`      | 'left' |
| `color`        | `string`          | -           |
| `transform`    | `"uppercase"      | "lowercase" | "capitalize"` | -      |
| `weight`       | `HeadingWeight`   | 'bold'      |
| `tracking`     | `HeadingTracking` | 'normal'    |
| `noMargin`     | `boolean`         | false       |
| `keepWithNext` | `boolean`         | -           |
