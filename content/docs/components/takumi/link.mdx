## API Reference

### Link

| Prop        | Type            | Default   |
| ----------- | --------------- | --------- | -------- | ------ |
| `href`      | `string`        | -         |
| `align`     | `"left"         | "center"  | "right"` | 'left' |
| `color`     | `string`        | -         |
| `variant`   | `LinkVariant`   | 'default' |
| `underline` | `LinkUnderline` | 'always'  |
