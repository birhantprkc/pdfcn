## API Reference

### Text

| Prop         | Type                                         | Default    |
| ------------ | -------------------------------------------- | ---------- |
| `variant`    | `TextVariant`                                | `'base'`   |
| `align`      | `'left' \| 'center' \| 'right' \| 'justify'` | `'left'`   |
| `color`      | `string`                                     | -          |
| `weight`     | `TextWeight`                                 | `'normal'` |
| `italic`     | `boolean`                                    | `false`    |
| `decoration` | `TextDecoration`                             | `'none'`   |
| `transform`  | `'uppercase' \| 'lowercase' \| 'capitalize'` | -          |
| `noMargin`   | `boolean`                                    | `false`    |
