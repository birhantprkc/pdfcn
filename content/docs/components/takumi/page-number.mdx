## API Reference

### PdfPageNumber

| Prop       | Type              | Default                                      |
| ---------- | ----------------- | -------------------------------------------- |
| `format`   | `string`          | 'Page &#123;page&#125; of &#123;total&#125;' |
| `align`    | `PageNumberAlign` | 'center'                                     |
| `size`     | `PageNumberSize`  | 'sm'                                         |
| `fixed`    | `boolean`         | false                                        |
| `muted`    | `boolean`         | true                                         |
| `children` | `never`           | -                                            |
