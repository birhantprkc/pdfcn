## Usage

```tsx
import { PdfAlert } from "@/components/pdf/alert";
```

```tsx
<PdfAlert variant="info" title="Info">
  Alert body
</PdfAlert>
```

## API Reference

### PdfAlert

| Prop         | Type           | Default |
| ------------ | -------------- | ------- |
| `variant`    | `AlertVariant` | 'info'  |
| `title`      | `string`       | -       |
| `children`   | `ReactNode`    | -       |
| `showIcon`   | `boolean`      | true    |
| `showBorder` | `boolean`      | true    |
