## Usage

```tsx

```

```tsx
<PdfImage src="/logo.png" width={120} />
```

## API Reference

### PdfImage

| Prop           | Type              | Default   |
| -------------- | ----------------- | --------- | --- |
| `src`          | `PdfImageSrc`     | -         |
| `variant`      | `PdfImageVariant` | 'default' |
| `width`        | `number           | string`   | -   |
| `height`       | `number           | string`   | -   |
| `fit`          | `PdfImageFit`     | -         |
| `position`     | `string`          | '50% 50%' |
| `caption`      | `string`          | -         |
| `aspectRatio`  | `number`          | -         |
| `borderRadius` | `number`          | -         |
| `noWrap`       | `boolean`         | true      |
| `style`        | `Style`           | -         |
