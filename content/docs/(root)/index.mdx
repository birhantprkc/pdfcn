# pdfcn

A registry of PDF primitives, layouts, and document blocks with **100% parity** across two bases:

- **Takumi PDF** — JSX/Tailwind to paged PDF (WASM). Browser preview via `react-pdf`.
- **Forme PDF** — React primitives with Forme’s layout engine. Client and server render.

## Install

```bash
npx shadcn@latest add @pdfcn/takumi/text
npx shadcn@latest add @pdfcn/forme/invoice-minimal
```

## Bases

Switch bases in the docs to see the same component implemented for each engine. Public props and variants match [pdfx](https://github.com/akii09/pdfx) — only the PDF primitives differ.
